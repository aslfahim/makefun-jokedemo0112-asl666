# The joke about the demo

Entry for the make.fun bounty [The joke about the demo](https://make.fun/bounty/the-joke-about-the-demo-20261123-0112).

`main.ts` (Node 22) writes one one-line joke about working beside AI coding
agents to `/output/entry.txt`. The joke's angle is role reversal: the agent
finishes writing the code and then asks the human to explain what it does —
so the demo turns into the human's own code interviewing them for their job.
